About The Mesh Guys

The Mesh Guys is a hub for mesh networking communities and creators. Our goal is to connect groups across the country and provide a place where people can share projects, guides, updates, and ideas about decentralized communication systems.

Chicagoland Mesh - Owned by ddthekidd

Chicagoland Mesh is a community-driven Meshtastic network focused on building long-range, off-grid communication across the Chicago area. The project connects local radio and mesh enthusiasts who use LoRa devices to create a decentralized messaging network that works without cell service or internet. Chicagoland Mesh helps users learn about Meshtastic, discover node coverage, join local discussions, and expand the mesh throughout Illinois and surrounding regions.

Website: https://chicagolandmesh.org/
Discord: https://chimesh.org/discord

Meshconsin - Owned by Carl Rosenthal

Meshconsin is a Wisconsin-based Meshtastic community focused on building a decentralized, off-grid communication network using LoRa radios. The network allows users to send encrypted messages without relying on cell towers, Wi-Fi, or the internet. Meshconsin brings together radio enthusiasts, tech hobbyists, and emergency preparedness communities to expand mesh coverage across Wisconsin while promoting open-source communication and resilient local networking.

Website: https://meshconsin.org/
